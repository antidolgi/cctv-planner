## 3. Модели данных (ключевые)

### User
- `id`: int, pk
- `email`: str, unique
- `password_hash`: str

### Project
- `id`: int, pk
- `user_id`: FK → User
- `name`: str
- `plan_image_url`: str (путь к плану)
- `walls`: JSON (массив стен)
- `devices`: JSON (массив устройств, см. ниже)
- `created_at`: datetime

### Equipment (справочник)
- `article`: str, pk
- `name`: str
- `category`: str (camera, recorder, switch)
- `angle_h`: float (горизонтальный угол обзора)
- `angle_v`: float (опционально)
- `resolution`: str (1920×1080)
- `mount`: str (wall, ceiling)
- `price`: float

4. API-эндпоинты (MVP)
Загрузка прайс-листа

POST /api/equipment/upload (multipart/form-data, файл CSV)

CSV-колонки: article, name, category, angle_h, angle_v, resolution, mount, price

Парсинг, валидация, сохранение в Equipment (перезапись по article).

Ответ: количество записей.

Каталог оборудования

GET /api/equipment?category=camera&search=...

Проекты

POST /api/projects — создать

GET /api/projects — список

GET /api/projects/{id} — детали

PUT /api/projects/{id} — обновить (walls, devices)

DELETE /api/projects/{id}

AI-аудит (самое важное!)

POST /api/projects/{id}/audit

Логика:

Собрать все камеры проекта, для каждой подтянуть angle_h, resolution из Equipment.

Сформировать описание сцены (стены, камеры) в JSON.

Отправить запрос в DeepSeek API (https://api.deepseek.com/v1/chat/completions) с промптом, требующим найти слепые зоны, проверить плотность пикселей и дать рекомендации.

Ответ ИИ вернуть фронтенду.

Модель: deepseek-chat

Аутентификация: Authorization: Bearer sk-a4e6c235b1c84d2aa8944b6cba6ed52b

💡 5 новых функций, которые заставят инвестора достать чековую книжку
Автоматический подбор регистратора
Система анализирует количество и характеристики камер (разрешение, кодек, битрейт) и сама предлагает модели NVR с нужным числом каналов и запасом жёсткого диска. Пользователь видит зелёную галочку «Совместимость: ✅».

Расчёт PoE-бюджета
Подсчитывается суммарное энергопотребление всех камер, выводится мощность коммутатора и проверяется, хватает ли лимита. При недостатке — рекомендация заменить или добавить второй коммутатор.

Подбор кабеля и расчёт метража
Пользователь рисует кабельные трассы прямо на плане, а система автоматически считает их длину и предлагает оптимальный тип кабеля (UTP/оптика) в зависимости от расстояния.

Расчёт стоимости «под ключ»
Мгновенная смета: стоимость всех камер + регистратора + коммутатора + кабеля + монтаж (из рассчитанного метража). С учётом реальных российских цен, данные для которых мы берём с рынка.

Интерактивный инспектор слепых зон
При наведении на любую точку плана система показывает, какими камерами она просматривается и с какой пиксельной плотностью. Приоритетная зона + плотность — это и есть наш будущий AI-аудит.

🔌 Как мы подключим твой API DeepSeek
Вот точная инструкция для Python-бэкенда (можно передать студенту):

URL эндпоинта: https://api.deepseek.com/v1/chat/completions

Аутентификация: HTTP-заголовок Authorization: Bearer sk-a4e6c235b1c84d2aa8944b6cba6ed52b

Модель: deepseek-chat

Цены (последние):

Входные токены (попадание в кеш): $0.028 за 1 млн (~2,3 рубля по курсу 80).

Выходные токены: ~$0.42 за 1 млн.

Бесплатный лимит: 10 миллионов токенов при регистрации — этого достаточно для тысяч бесплатных аудитов на этапе разработки.

Схема простая: сервер получает сцену → формирует промпт → шлёт в DeepSeek → получает структурированный ответ с ошибками и рекомендациями → возвращает фронтенду.

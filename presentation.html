Видео Помощник

Интеллектуальная платформа проектирования систем видеонаблюдения с AI-аудитом мёртвых зон

🔴 Проблема

Инженеры тратят до 40% времени на расстановку камер вручную. Ошибки в проектах приводят к «слепым» зонам, перерасходу бюджета и судебным искам. Существующие решения дороги, сложны и лишены интеллектуального анализа.

🟢 Наше решение

Облачная платформа с ИИ-ассистентом, доступная из браузера. Мгновенный аудит проекта, автоматический подбор оборудования, полная смета «под ключ» в рублях. Поддержка любого прайс-листа (CSV) — максимальная гибкость для российских монтажных организаций.

Цель продукта

Web-приложение для проектирования видеонаблюдения с встроенным AI-аудитом. Пользователь загружает план, расставляет камеры, получает анализ покрытия и спецификацию (BOM).

Технологический стек

Frontend
React 18 + TypeScript, Konva.js (2D-холст), React Three Fiber (3D), TailwindCSS
Backend
Python 3.11 + FastAPI, SQLAlchemy, Alembic
Базы данных
PostgreSQL (основная), Redis (сессии/кеш)
AI-модуль
DeepSeek API (аудит проекта), интеграция через HTTP
Хранение файлов
AWS S3 / MinIO (планы, проекты)
DevOps
Docker, GitHub Actions, Nginx

Архитектурная схема

Модель данных (основные сущности)

User
id, email, password_hash, subscription
Project
id, user_id, name, plan_url, walls_json, devices_json
Device (камера, свитч)
id, project_id, type, x, y, angle, mount, article
Equipment (справочник)
article(PK), name, category, angle_h, angle_v, resolution, mount, price

AI-интеграция (DeepSeek API)

Backend формирует JSON с координатами камер, стен, параметрами углов обзора. Запрос к DeepSeek возвращает список проблемных зон и рекомендаций. Документация API. Бесплатный лимит 10 млн. токенов.

Требования к MVP

  • Регистрация/авторизация (JWT)
  • Загрузка плана этажа (PNG/JPG) как подложка
  • Масштабируемый холст с сеткой (Konva.js)
  • Инструменты: стена, камера, выбор/редактирование
  • Загрузка CSV с оборудованием, динамический каталог
  • Визуализация зоны обзора (сектор) с учётом угла и ориентации
  • Расчёт пиксельной плотности (цветовое кодирование)
  • AI-аудит: кнопка «Анализ», запрос к DeepSeek, подсветка проблем
  • Панель свойств выделенного объекта
  • Сохранение/загрузка проекта (сервер + локальный JSON)
  • Генерация PDF-отчёта (BOM)

План для разработчика

Этап 0 (сейчас): Статический прототип на HTML/Canvas с зонами обзора и CSV-парсером.
Этап 1 (MVP): React + FastAPI, интеграция DeepSeek, первые пользователи.
Этап 2: 3D, отчёты, мобильная версия (React Native).
